# Tree silhouette source

Tree Icons by Woodcutter (2018).

Author's font page: https://www.dafont.com/tree-icons.font

Download: https://dl.dafont.com/dl/?f=tree_icons

Author's own note on the page: "100% free", "Compiled and Vectorized", "WOODCUTTER", "MMXVIII". Archive contains `Tree Icons.otf`; no separate license document was included. Keep the source note with these assets. This is not an OFL or CC0 license assertion.

The font has been cached here for local rendering; it has not been installed in Windows. Each added stamp records its source glyph in the manifest. Trees were rendered from actual glyph outlines, fitted within 76x112 native pixels, and converted to a single existing game-palette color with binary transparency. Tiny branches may need manual cleanup at that resolution.
