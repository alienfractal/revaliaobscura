# Organic tree source artwork

All five source designs are from Openclipart, whose published policy dedicates uploaded clipart to CC0 1.0 and permits modification and commercial use:
https://openclipart.org/share

| Design | Artist | Original source |
|---|---|---|
| Irregular woodland tree | mazeo | https://openclipart.org/detail/244035/tree-silhouette |
| Spreading leafy tree | GDJ | https://openclipart.org/detail/328207/highly-detailed-tree-silhouette |
| Gnarled bare oak | IggyOblomov | https://openclipart.org/detail/188718/oak-tree |
| Umbrella pine | waielbi | https://openclipart.org/detail/174787/pinus-pinea |
| Old broad oak | GDJ | https://openclipart.org/detail/286758/detailed-large-oak-tree-silhouette |

Original PNG previews are retained here. The game stamps are silhouette conversions fitted to two bounding boxes: 76x112 and 152x224 pixels. They retain aspect ratio; actual dimensions vary. Both sizes use only the existing olive-green palette color and binary transparency. Fine twigs become simplified at small sizes.

`239959.png` was reviewed but excluded: it depicts an oak sprig, not a whole tree.
